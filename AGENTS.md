# Респейс

Дипломный исследовательский pet-проект: пространство после игры, учебные практики и свободный досуг. Текущий этап — лёгкий, приятный интерфейс с короткими шагами по примеру Duolingo и собственными персонажами, с сохранением работающего функционала.

- Прочитай относящийся к изменению документ в `docs/`. Не называй авторские игры лечением, диагностикой или доказанным средством от выгорания.
- Свободный досуг доступен без курса, наград, ежедневных серий и штрафов. Звук и движение добровольны; учитывай клавиатуру, телефон и reduced motion.
- Используй установленный Build Web Apps для фронтенд-задач и web-design-guidelines для проверки UI. Подключай только нужный навык, не загружай весь набор.
- Сохраняй совместимость гостевых данных. Личные записи передаются в облако только при выборе пользователя.
- Проверка: `pnpm test`, `pnpm build`, затем реальное действие в браузере и повторное открытие сохранения. Нельзя считать заглушку работающим сервисом.
- Задачу формулируй как результат и критерии приёмки; архитектуру выбирай по текущему коду. Предпочитай небольшой работающий сценарий с визуальной и интерактивной проверкой.
- У каждой игры есть понятный выход и сохранение результата. Оценки игрового результата не интерпретируются как психологические показатели. Исследование с участниками — отдельная добровольная процедура.
- Проверка инструкций — `prompt-audit`, игры — `wellbeing-game-builder`, повторяющиеся процессы — `reliable-agent-automations`. Не создавай расписания только из-за установки навыка. После неопределённой записи проверь результат перед повтором; фиксируй успех только после подтверждения.
