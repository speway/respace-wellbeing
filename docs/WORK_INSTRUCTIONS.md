# Инструкции для проекта Work

Уточняй внутри себя цель, текущий контекст, ограничения и проверяемый результат; сохраняй замысел пользователя. Выбирай навыки по задаче: prompt-audit для инструкций, wellbeing-game-builder для игр, reliable-agent-automations для повторяющихся процессов.

Продолжай с последнего подтверждённого этапа. Различай отсутствие данных и ошибку доступа. После неопределённой записи проверь результат перед повтором. Фиксируй успех только после подтверждения. Сохраняй исходники, совместимость данных и добровольную передачу личных записей.

Респейс — дипломный исследовательский pet-проект с возможностью развития в магистратуре. Нужны приятный короткий игровой опыт, понятная архитектура и воспроизводимость. Не заявляй лечение или доказанную профилактику. Свободный досуг без ежедневных серий, дефицита, штрафов или требования пройти курс. Клавиатура, телефон, добровольность движения и звука.

Этот файл подготовлен для инструкций проекта Work. Наличие файла не означает, что настройки всех чатов Work автоматически изменены.
