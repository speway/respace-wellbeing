# Как продолжать разработку Респейса

Рабочий прототип развивается небольшими проверяемыми изменениями. Текущая архитектура: Vite и TypeScript, Capacitor, Vercel Functions, Better Auth и Neon. Подключение новых инструментов само по себе не является причиной миграции.

## Краткий промпт для следующей задачи

«Продолжи Респейс с последнего подтверждённого состояния. Прочитай AGENTS.md и документ сценария в docs. Реализуй [конкретное поведение пользователя]. Сохрани гостевой доступ, совместимость JSON и добровольную передачу личных данных. Готовность: действие работает в браузере, сохранение восстанавливается после повторного открытия, профиль другого пользователя недоступен, pnpm test и pnpm build проходят. Сообщи проверенный результат и оставшиеся ограничения. Визуальные изменения выполняй только в пределах текущей задачи».

## Инструменты по назначению

- `wellbeing-game-builder` — игровое действие, результат, выход, клавиатура, сохранение и повторное открытие. Не добавлять скрытую психологическую оценку.
- `prompt-audit` — проверка промптов и инструкций с сохранением цели и уже принятых решений.
- Build Web Apps, `frontend-testing-debugging` — проверка действующего интерфейса, ошибок и состояний. Текущий этап — визуальная переработка по ImageGen-референсу в docs/design/home-concept.png. Сохранять рабочие сценарии и совместимость данных.
- `web-design-guidelines` — целевой аудит доступности и взаимодействий, без обязательного изменения стека.
- Vercel skills — окружение, публикация, журналы, база и авторизация.
- Figma — подключён для задач с макетами; не требуется переносить туда каждую правку.

Каждая проверка фиксирует конкретное наблюдение. Успешная сборка не подтверждает работу API. Пустой журнал не подтверждает отсутствие ошибок доступа. Перед повтором неопределённой облачной операции сначала проверить существующий результат.

## Дополнительные инструменты

Установка подтверждена 13 октября 2026 года: OpenAI Developers, Context7 и Superpowers. Context7 использовать для актуальной документации библиотек; OpenAI Developers — для подходящих задач с OpenAI; Superpowers — для применимых процедур разработки. Наличие плагина не требует добавлять AI-функции, менять базу или усложнять текущую задачу.

Из официального репозитория `openai/skills` добавлены `figma-create-design-system-rules` и `playwright-interactive`. Первый применим к задачам с дизайн-системой, второй — для интерактивной проверки, когда это допускают доступные браузерные инструменты. Локальные `prompt-audit` и `wellbeing-game-builder` уже доступны. Не загружать все эти инструкции одновременно: выбирать нужные для конкретного изменения.

## Персонаж и визуальные материалы

Ри и новые иллюстрации созданы по единому референсу через ImageGen. Спецификация — `docs/design-v2.md`. Видеопроект — `media/ri-studio`, две композиции Remotion; его зависимости устанавливаются отдельно, сборка сайта его не включает. Шрифт Nunito хранится локально. Подтверждённые предпочтения сохранены отдельной заметкой в памяти Codex; переносимые инструкции Work — `docs/WORK_INSTRUCTIONS.md`. Файл Work сам по себе не меняет настройки облачных чатов.
