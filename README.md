# Респейс

Рабочий дипломный прототип: короткие учебные темы, научпоп и добровольное самонаблюдение для взрослых игроков. Игровые пространства сейчас закрыты на переработку. Это не терапия и не диагностика; эффективность Респейса как психологического вмешательства не проверена.

Сайт: https://respace-wellbeing-iqd2.vercel.app

Это Git-подключённая production-публикация проекта. Старый адрес `respace-wellbeing.vercel.app` пока остаётся на отдельном Vercel-проекте, который не обновляется push-коммитами из этого репозитория.

## Доступно сейчас

- 12 тем с историями, сопоставлением, выбором и необязательной рефлексией. Позиция в теме сохраняется; личные ответы — только при выборе сохранения в конце.
- 15 научпоп-карточек с источниками, ограничениями выводов, тематическими фильтрами и избранным.
- Дневник: заметку можно оставить без шкал; оценки и дополнительные отметки добавляются отдельно и только по желанию. График строится по сохранённым оценкам.
- Опоры, шесть быстрых практик и таймер перерыва.
- Немедленный гостевой доступ с локальным сохранением. Код необязательного аккаунта, переноса гостевого прогресса и облачного сохранения есть, но в текущей production-публикации кабинет недоступен до настройки серверного окружения.
- JSON-копия всего профиля, восстановление и CSV дневника. Старые гостевые JSON совместимы.

## Игровые пространства закрыты на переработку

Раздел `#play` сейчас показывает экран паузы. Комната Ри, Небо Нори, Почта Бипа, интерактивная история и музей недоступны для запуска. Ранее сохранённые игровые данные остаются в профиле и резервной копии; закрытие гейта не удаляет и не интерпретирует их. Возврат любого модуля требует отдельной содержательной, технической и доступностной проверки и самостоятельного решения владельца.

## Локальное хранение и облачный кабинет

Гостевое сохранение работает в `localStorage` браузера. Облачный кабинет реализован в коде, но сейчас production API на Vercel возвращает ошибку запуска функции, поэтому регистрация, вход и синхронизация недоступны. Данные гостя остаются на устройстве; приложение не отправляет их в облако автоматически.

Когда облачный кабинет будет подключён, по умолчанию в нём должны находиться учебный прогресс, избранное, предметы комнаты, линии созвездия и маршрут истории. Дневник, заметки, названия опор, название созвездия и ориентир передаются только при включённом пользователем переносе личной части.

Проектный серверный код использует Better Auth и Postgres/Neon. Production-окружение Git-подключённого проекта ещё требует настройки; до этого кабинет следует считать недоступным. Пароли не хранятся в браузерном прогрессе. Это не сквозное шифрование: владелец сервиса технически имеет доступ к базе. Передача в исследование не происходит автоматически.

## Локальная разработка

Node.js 24+, pnpm. Установить зависимости: `pnpm install`. Проект связан с Git-публикацией Vercel `spw1/respace-wellbeing-iqd2`; `.env.local` содержит реальные переменные базы и не включается в Git или загрузку исходников.

Для восстановления окружения: `vercel env pull .env.local --yes --scope spw1`. Затем для локального запуска задать `BETTER_AUTH_URL=http://127.0.0.1:5173` только в локальном файле. Значения секретов не выводить.

В отдельных терминалах: `pnpm dev:api` (API на 3001) и `pnpm dev` (сайт на 5173; Vite перенаправляет `/api`). Одного Vite достаточно для гостевых занятий, но настоящий кабинет требует API. После изменения схемы: `pnpm db:migrate`.

Проверки: `pnpm test`, `pnpm build`. `scripts/verify-api.mjs` проверяет настоящий API, создавая и удаляя синтетические аккаунты. Скрипт никогда не использует реальные персональные записи.

Публикация текущего проекта: `vercel deploy --prod --scope spw1`. Локальный `.vercel/project.json` должен указывать на Git-проект `respace-wellbeing-iqd2`; старый проект `respace-wellbeing` не использовать для публикации текущего кода. В `tsconfig.json` включено преобразование относительных `.ts` импортов для Node.js-сборки Vercel.

## Телефон

Веб-приложение можно добавить на главный экран Android и iPhone. После первой полной загрузки локальные занятия работают офлайн; вход и облако требуют сети. API и аккаунт не кешируются сервис-воркером.

Исходные проекты Capacitor находятся в `android/` и `ios/`. Обновить веб-сборку в них: `pnpm mobile:sync`. Android открывается в Android Studio, iOS — в Xcode на Mac. Подписанные APK/IPA и проверка на физических устройствах в эту итерацию не входят. В текущих нативных оболочках работает гостевой локальный режим; production-облачный кабинет сейчас недоступен и на реальных мобильных устройствах не проверен.

## Что ещё нужно

Почтовое восстановление и подтверждение email пока отсутствуют: интерфейс предупреждает об этом, смена пароля требует текущего. Следующая работа — восстановление аккаунта, проверки на реальных телефонах, пользовательская и психологическая экспертиза материалов. Визуальная переработка v2 выполнена по собственному референсу. Серий, платных предметов, штрафов и блокировки игр курсом нет.

Концепция и сценарии: `docs/`. Решения по кабинету: `docs/account-and-progress.md`.

## Интерфейс v2 и Ри

Главная предлагает выбрать ситуацию (страх пропустить, переживаемая обязанность, переход после сессии) и открыть соответствующую учебную тему или практику. Выбор не сохраняется как психологический показатель. Темы, научпоп и кабинет доступны; игровые пространства остаются закрытыми на переработку. Комната и другие игровые места используют собственные иллюстрации и сохраняемые данные, но текущий публичный интерфейс не позволяет их запускать. Таймер перерыва доступен с главной.

Референс и решения: `docs/design-v2.md`. Персонаж Ри в шести позах и игровые иллюстрации — `public/art/`. Две редактируемые видеокомпозиции (12 секунд, вертикальная и горизонтальная) — `media/ri-studio/README.md`. Это отдельный Remotion-проект: `pnpm install`, `pnpm dev` из его папки. Готовый MP4 не заявляется: экспорт выполняется отдельно по инструкции.
