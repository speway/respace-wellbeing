# Ри: персонаж для видео Респейса

Remotion 4.0.535, React 19.2.3. Отдельный проект, не часть клиентской сборки сайта.

Две композиции по 12 секунд, 30 fps: `RiIntroPortrait` (1080×1920) и `RiIntroLandscape` (1920×1080). Три состояния Ри: приветствие, чтение, отдых. Все движения зависят от кадра, без CSS-анимаций. Слои имеют имена и редактируются в Studio. Звук отсутствует, текстовые фразы видны в кадре. Спрайт-лист содержит шесть поз для дальнейших роликов.

Из этой папки: `pnpm install`, `pnpm dev`. Открыть адрес, который покажет Studio. Проверка: `pnpm lint`, `pnpm build`.

Для экспорта по запросу: `pnpm exec remotion render src/index.ts RiIntroPortrait out/ri-portrait.mp4` (или `RiIntroLandscape`). Это инструкция экспорта, не утверждение о наличии готового MP4. Перед публикацией проверить кадры начала, смены сцен и окончания. Оригинальный персонаж создан ImageGen по единому референсу; шрифт Nunito с лицензией лежит в public.
